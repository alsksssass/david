# 경로 추천 서비스 경쟁 제품 기능 조사

## 1. 조사 대상 서비스
본 조사는 대한민국에서 널리 사용되는 지도 기반 경로 추천 서비스를 대상으로 한다.

### **대상 서비스**
1. 네이버 지도
2. 카카오내비(카카오맵 길찾기)

---

## 2. 서비스 비교 분석

## (1) 화면 구성 비교

### ✔ 네이버 지도
- 지도 좌측/하단에 경로 정보 표시
- 지도 상단에 목적지 검색창
- 교통 현황(실시간 도로 정체 표시)
- 여러 경로 선택 버튼이 명확하게 정렬됨

### ✔ 카카오내비(카카오맵)
- 경로 정보가 화면 하단에 카드 형태로 표시됨
- 지도 화면은 대부분 넓게 유지
- 검색창은 상단에 배치
- 도보·대중교통·자동차 경로 모두 제공

---

## (2) 추천 경로 유형

| 서비스 | 추천 경로 종류 |
|--------|----------------|
| 네이버 지도 | 최단거리, 자동차 전용, 초보자·고속도로 우선, 대중교통(버스/지하철) |
| 카카오내비 | 최단시간, 추천 경로, 톨게이트 최소, 교통 혼잡 회피, 대중교통 |

---

## (3) 지도 상에서 경로 표시 방식

### ✔ 네이버 지도
- 선택된 경로는 **굵은 파란색**으로 표시
- 대안 경로는 **연한 회색 또는 얇은 라인**
- 실시간 교통 색상(빨강, 주황, 초록) 병행 표시

### ✔ 카카오내비
- 추천 경로는 **굵은 파란색 라인**
- 대안 경로는 **회색 점선 or 얇은 선**
- 실시간 교통량 색상 제공

---

## (4) 지도 외부 영역에서 경로 표시 방식

### ✔ 네이버 지도
- 경로 리스트를 세로로 나열해 거리, 소요시간, 톨비 등 정보 제공  
- 상세 정보를 누르면 경유지, 도로 종류, 비용 등 세부 정보 제공  
- UI가 다소 복잡하지만 제공 정보가 풍부함

### ✔ 카카오내비
- 카드 형태로 한눈에 비교 가능  
- 정보 표시가 직관적이며 시각적 가독성이 좋음  
- 선택 시 상세 경로 안내로 자연스럽게 이동

---

## (5) 경로 추천 조건 입력 방식

### ✔ 네이버 지도
- 출발/도착지 직접 입력  
- 장소 검색 후 “길찾기” 클릭  
- 경유지 추가 가능  
- 자동차/도보/대중교통 선택 메뉴 존재  
- 옵션: 고속도로 우선, 자동차 전용도로 제외, 톨비 최소 등

### ✔ 카카오내비
- 목적지 검색 후 “길찾기” 버튼  
- 출발지 자동 설정(현재 위치)  
- 경유지 3개까지 설정  
- 자동차/대중교통/도보 선택  
- 옵션: 톨비 최소화, 교통 혼잡 회피, 무료도로 경로 등

---

## (6) 기타 기능 비교

| 항목 | 네이버 지도 | 카카오내비 |
|------|-------------|-------------|
| 실시간 교통 | 제공 | 제공 |
| 실시간 사고 정보 | 표시 | 표시 |
| 음성 내비게이션 | 제공 | 제공 |
| 즐겨찾기 | 제공 | 제공 |
| 주차장 정보 | 제공 | 제공 |
| 연료 가격 안내 | 일부 제공 | 일부 제공 |
| UI 직관성 | 중간 | 매우 높음 |
| 경로 품질 | 안정적 | 운전자 중심 최적화 |

---

## 3. 분석 결과 요약

- **네이버 지도**는 세부 정보가 많아 전문가형 사용자 또는 “정보 중심 사용자”에게 유리하다.  
- **카카오내비**는 UI가 직관적이며 모바일 환경에서 특히 사용성이 뛰어나다.  
- 두 서비스 모두 실시간 교통 기반 경로 계산 기능이 우수하며, 기본적인 경로 추천 로직은 매우 안정적이다.

---

## 4. 경로 추천 서비스 설계 시 시사점

1. UI는 **카드형 요약 + 상세 화면 구조**가 가장 가독성이 좋다.  
2. 추천 경로는 **3가지 정도(추천 / 최단거리 / 혼잡 회피)** 제공이 적당하다.  
3. 실시간 데이터(교통량, 사고 정보)를 반영할 수 있으면 품질이 크게 향상된다.  
4. 출발지·목적지 입력은 모바일 기준으로 가장 간단하게 구성해야 한다.  
5. 초보자는 복잡한 옵션을 원하지 않으므로 기본 옵션을 단순화하는 것이 좋다.
